# LoraVie FREE: пустой список новых подписчиков в 0.1.53

Источник: переданный пользователем журнал запуска от 2026-09-14T22:46:31.573Z.
Окно — 72 часа, потерянных событий нет. Два HTTP 200: welcome-шаблон и
первая страница `/fans/all`, limit=20, offset=0. Запуск завершился через 4513 мс.
429 и ошибок запросов в этом запуске нет.

Получено 18 фанов. Их даты подписки перемешаны, от 2025-09-27 до 2026-07-28;
ни одна не входит в запрошенные 72 часа. Это подтверждает результат фильтрации
именно этой страницы, но не отсутствие новых подписчиков у аккаунта.
В журнале нет hasMore/next_page, поэтому точная ветка остановки не доказана.

Подтверждённые дефекты реализации:

- Старые даты всей страницы считались основанием закончить обход, хотя порядок
  дат не соблюдался.
- Следующий offset рассчитывался по числу возвращённых записей; провайдер может
  возвращать неполную промежуточную страницу и отдельный next_page.

Исправление: датированная выборка `/fans/latest?type=new`, точная локальная
проверка интервала, проверенный offset из next_page, явная полнота, ограниченный
обход. Журнал теперь объясняет страницы и причину завершения. Только этот
серверный ресурс отнесён к core_audience; явно созданные старые задания
profile_notifications сохраняют возможность продолжиться с прежними лимитами.

Независимый агент проверил обе реализации. Тесты включают 18 дат инцидента,
700 фанов на неровных страницах, пустые страницы, дубликаты, изменение границ
и чужие cursor URL, паузу через полночь, сохранённые серверные задания и off.

Не проверено: фактическая выдача нового endpoint на живой Lora и недокументированная
семантика returning subscriber/type=new. Локальный ChatGoose не авторизован.
Исправление включено в кандидат 0.1.54; публикация подтверждается лентами обновлений.

Проверено: полный pnpm check обоих репозиториев, 2377 desktop/shared тестов,
3845 Hub unit-тестов и 49 PostgreSQL integration-тестов. Подробный контракт —
[followers.md](followers.md). Первичная документация провайдера —
[List Latest Fans](https://docs.onlyfansapi.com/api-reference/fans/list-latest-fans).
