Установка

  1. Запусти актуальный файл ChatGoose-Setup-<version>.exe, который прислал владелец.
  2. Windows покажет синее окно «Система Windows защитила ваш компьютер». Это ожидаемо — программа пока без цифровой подписи. Нажми «Подробнее», затем «Выполнить в любом случае».
  3. Установка пройдёт сама, без вопросов и без прав администратора; в конце ChatGoose запустится, появятся ярлыки на рабочем столе и в меню «Пуск».
Что должно бытьУстановка дошла до конца, на ярлыке нарисован гусь, а не серый квадрат.
А1

Первый запуск и шрифты

Программа открывается «пустой» — без входа так и должно быть, чаты появятся в части Б.

  1. Окно открылось: светлый интерфейс, сверху надпись ChatGoose.
  2. Открой настройки: Ctrl+, (Ctrl и запятая). Слева — разделы: «Активность», «Аккаунт», «Персоналии», «Поведение», «Спендеры», «Локальные данные», «Обновления».
  3. Посмотри на русский текст: буквы ровные, без «квадратиков», не похоже, что половина букв из другого шрифта.
А2

Горячие клавиши показывают Ctrl, а не ⌘

Программу делали на «маке»; проверяем, что на Windows нигде не вылезает маковский символ ⌘.

  1. Нажми Ctrl+K — откроется строка поиска команд. В подсказках написано Ctrl+E, Ctrl+Alt+S и т.п.
  2. Закрой её (Esc) и нажми ? (Shift и /) — откроется шпаргалка клавиш. Пройдись глазами: всюду Ctrl+… или Ctrl+Alt+…, символа ⌘ нет нигде.
  3. Хоткеи те же, что в расширении для Fansly: Reply — Ctrl+E, Improve — Ctrl+I, Hi — Ctrl+G, Ping — Ctrl+P, отмена — Ctrl+.; разборы и панели — Ctrl+Alt+буква. Проверь на английской и русской раскладке: срабатывают, язык ввода не переключается.
  4. Кнопка поиска наверху окна тоже показывает Ctrl+K.
А3

Масштаб интерфейса

  1. Настройки → раздел «Поведение» → «Масштаб интерфейса»: поменяй значение — всё окно плавно увеличивается/уменьшается и остаётся чётким.
  2. Если у монитора системный масштаб 125–150% (часто на ноутбуках) — глянь, не размыт ли текст программы в целом.
А4

Повторный запуск — важная проверка

  1. Не закрывая ChatGoose, запусти его ярлыком ещё раз. Правильно: второе окно не открывается, существующее выходит на передний план.
  2. Теперь сверни окно и снова запусти ярлыком: окно разворачивается и оказывается сверху.
А5

Язык интерфейса

  1. Настройки → «Поведение» → «Язык»: переключи EN ↔ RU — подписи настроек меняются сразу.

Рабочая область чатов пока частично на английском — так задумано на этом этапе, это не ошибка.

А6

Проверка обновлений

  1. Настройки → раздел «Обновления» → кнопка «Проверить обновления».
  2. Если новой версии нет — появится «Установлена последняя версия».
  3. Если владелец специально выложил новую версию для проверки — приложение само её скачает (видно проценты), затем появится кнопка «Перезапустить и установить». Нажми — приложение закроется, обновится и откроется уже новой версии (номер версии вверху раздела изменится).

Приложение обновляется и само, в фоне, и ставит обновление при выходе — кнопка нужна, только когда хочется обновиться прямо сейчас.

Стоп — дальше только с владельцемПроверки Б1–Б5 выполняются на созвоне с владельцем: ты входишь под выделенным для проверки логином. Всё дальше — «только чтение»: никому ничего не отправляем.
Б1

Вход переживает перезапуск — главная проверка Windows

  1. При первом запуске программа сразу открывает экран входа: введи свои логин и пароль, нажми «Войти».
  2. Нажми «Проверить подключение» → должно появиться подтверждение, что подключение работает.
  3. Полностью закрой программу и запусти заново.
  4. Снова открой Настройки → «Аккаунт»: там по-прежнему «Вы вошли как …», повторно вводить пароль не нужно. Нажми «Проверить подключение» ещё раз.
Если не сработалоПосле перезапуска снова показан экран входа или проверка подключения падает — это самая важная находка всей проверки (Windows не сохранил вход). Сообщи владельцу сразу, со скриншотом.
Б2

Чаты и картинки

  1. После входа слева появятся назначенные аккаунты и чаты; открой несколько.
  2. Аватарки фанатов и фото в переписке загружаются (с небольшой задержкой — нормально). Навсегда пустые серые прямоугольники вместо картинок — это проблема, отметь.
Б3

Уведомления

  1. Сверни окно ChatGoose.
  2. Владелец отправит тестовое сообщение в один из чатов.
  3. Должно всплыть обычное уведомление Windows (в правом нижнем углу) с именем фаната.

Если уведомления нет: проверь, что они включены в настройках программы («Поведение» → «Уведомления») и что в Windows не включён режим «Не беспокоить»/фокусировка.

Б4

Счётчик непрочитанных на панели задач

  1. Когда в чатах есть непрочитанные — поверх иконки ChatGoose на панели задач появляется красный кружок с числом.
  2. Когда всё прочитано (владелец отметит) — кружок исчезает.
Б5

Живая смена «только чтение», 30–60 минут

  1. Подержи программу открытой 30–60 минут, пока аккаунт живёт обычной жизнью.
  2. Сообщения появляются сами, без перезапуска; внизу в строке состояния обновляется время последнего обновления.
  3. Отмечай любые странности: зависания, пустые списки, окна ошибок, «съехавшую» вёрстку — со скриншотами.
