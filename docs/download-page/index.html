🍎macOS

Apple Silicon (M1–M4) · DMG
Скачать для macOS
1Открой DMG, перетащи ChatGoose в «Программы» и закрой окно установщика.
2Первый запуск — из папки «Программы» (Finder → Программы), не из окна установщика: правой кнопкой по ChatGoose → Открыть → «Открыть».
3Мак пишет «повреждено» / damaged или в окошке нет кнопки «Открыть»? Приложение целое — это защита macOS от программ без подписи. Открой Терминал (⌘+Пробел → «Terminal»), вставь строку целиком, нажми Enter и запусти ChatGoose снова:xattr -rd com.apple.quarantine /Applications/ChatGoose.appЭто нужно один раз.
4Вставь ключ чаттера или войди устройством — данные даст админ.
На маке автообновления нет — когда приложение или админ скажет про новую версию, скачай её с этой страницы и переустанови так же.
Сборки не подписаны сертификатами — скачивай их только с этой страницы. Вопросы — админу в Telegram.
