# Проверка ChatGoose на Windows — инструкция для помощника

> **HTML-версии этой инструкции** (галочки сохраняются сами, печатается в PDF):
> `docs/WINDOWS-VERIFICATION.html` — только часть помощника, её и отправляй
> помощнику; `docs/WINDOWS-GUIDE.html` — то же плюс владельческая часть (сборка
> инсталлера, учётная запись, созвон). Этот файл — текстовый первоисточник; при изменении
> процесса обновлять все три.

Эта инструкция для человека **без технических навыков**: никаких программ
ставить не нужно, кроме самого ChatGoose. Идём сверху вниз, по шагам. На каждом
шаге отмечай результат в таблице в конце файла («работает / не работает») и
делай скриншот, если что-то выглядит не так.

Часть Б выполняется **только вместе с владельцем по созвону** — там ты входишь
в ChatGoose под выделенным для проверки логином. Владелец может завершить этот
вход в любой момент. Сам по себе ChatGoose до входа ничего никуда не отправляет
и ни к чему не подключается.

Понадобится: компьютер с Windows 10 или 11, актуальный файл-установщик от
владельца (`ChatGoose-Setup-<version>.exe`), 30–60 минут.

---

## 1. Установка

1. Скачай/получи у владельца актуальный `ChatGoose-Setup-<version>.exe` и запусти его.
2. Windows покажет **синее окно «Система Windows защитила ваш компьютер»**
   (SmartScreen). Это ожидаемо: приложение пока не подписано цифровой подписью.
   Нажми **«Подробнее»**, затем **«Выполнить в любом случае»**.
3. Установка проходит сама, без вопросов и без прав администратора. По
   завершении ChatGoose запустится, появятся ярлыки на рабочем столе и в меню
   «Пуск».

✅ Что отметить: установка дошла до конца; на иконке нарисован гусь (не
стандартный квадратик Electron).

## 2. Часть А — без входа (можно одному)

Приложение открывается «пустым» — это нормально, подключение появится после
входа в части Б.

### А1. Первый запуск и шрифты

- Окно открывается: светлый интерфейс, сверху строка с надписью ChatGoose.
- Открой настройки: нажми **Ctrl+,** (Ctrl и запятая) — или найди их через
  палитру (шаг А2). Слева — разделы настроек («Активность», «Аккаунт»,
  «Персоналии», «Поведение», «Спендеры», «Локальные данные», «Обновления»).
- Посмотри на русский текст в настройках: буквы ровные, нет «квадратиков» и
  нет ощущения, что половина букв из другого шрифта.

### А2. Горячие клавиши показывают Ctrl, а не ⌘

Приложение разрабатывалось на «маке»; здесь проверяем, что на Windows нигде не
вылезает маковский символ **⌘**.

- Нажми **Ctrl+K** — откроется «палитра команд» (строка поиска по действиям).
  В подсказках команд должно быть написано `Ctrl+R`, `Ctrl+S` и т.п. — никаких ⌘.
- Закрой палитру (Esc) и нажми **?** (Shift+/) — откроется шпаргалка горячих
  клавиш. Пройдись глазами: все сочетания вида `Ctrl+…`, символа ⌘ нет нигде.
- Кнопка поиска наверху окна тоже должна показывать `Ctrl+K`.

### А3. Масштаб интерфейса

- Настройки → раздел **«Поведение»** → **«Масштаб интерфейса»**: поменяй
  масштаб — всё окно должно плавно увеличиться/уменьшиться и остаться чётким.
- Если у твоего монитора стоит системный масштаб 125%/150% (часто на ноутбуках)
  — посмотри, не размыт ли текст приложения в целом.

### А4. Повторный запуск (важная проверка)

1. Не закрывая ChatGoose, запусти его ярлыком **ещё раз**.
2. Правильное поведение: **второе окно НЕ открывается** — вместо этого
   существующее окно выходит на передний план.
3. Теперь сверни ChatGoose и снова запусти ярлыком: окно должно развернуться
   и оказаться сверху.

### А5. Язык

- Настройки → «Поведение» → **«Язык»**: переключи EN ↔ RU — подписи настроек
  меняются сразу. (Рабочая область чатов пока частично на английском — так и
  задумано на этом этапе.)

### А6. Проверка обновлений

- Настройки → раздел **«Обновления»** → кнопка **«Проверить обновления»**.
- Если новой версии нет — появится «Установлена последняя версия».
- Если владелец специально выложил новую версию для проверки — приложение само
  её скачает (видно проценты), и появится кнопка **«Перезапустить и
  установить»**: нажми — приложение закроется, обновится и откроется снова уже
  новой версии (номер версии вверху раздела изменится).
- Приложение и само обновляется в фоне и ставит обновление при выходе — кнопка
  нужна, только когда хочется обновиться прямо сейчас.

## 3. Часть Б — с владельцем по созвону (вход устройства)

Владелец создаёт или выбирает **отдельную учётную запись чаттера** с нужными
страницами. Здесь всё только «на чтение»: **ничего не отправляем фанатам**.
Любая отправка — только если владелец прямо говорит, что и куда (у него есть
специальный тестовый аккаунт для этого).

### Б1. Вход и его сохранность (главная проверка Windows)

1. При первом запуске программа сразу открывает **экран входа**: введи свои
   **логин и пароль**, нажми **«Войти»**.
2. Нажми **«Проверить подключение»** → должно появиться подтверждение, что
   подключение работает.
3. **Полностью закрой приложение** (правый клик по иконке в панели задач →
   закрыть) и запусти заново.
4. Снова открой Настройки → «Аккаунт»: там должно остаться «Вы вошли как …»,
   **повторно вводить пароль не нужно**. Нажми «Проверить подключение» ещё раз.
   Это проверяет, что Windows сохранил вход. Если после перезапуска снова
   показан экран входа или проверка падает — сообщи владельцу сразу.

### Б2. Чаты и картинки

- После входа в левой колонке появятся назначенные аккаунты и чаты; открой
  несколько.
- Аватарки фанатов и фотографии в переписке загружаются (могут появляться с
  небольшой задержкой — это нормально). Если вместо картинок пустые серые
  прямоугольники навсегда — отметь.

### Б3. Уведомления

1. Сверни окно ChatGoose.
2. Владелец отправит тестовое сообщение в один из чатов (или дождитесь живого
   входящего).
3. Должно всплыть **обычное уведомление Windows** (тост в правом нижнем углу) с
   именем фаната.
4. Если уведомления нет: проверь, что они включены в Настройках («Поведение» →
   «Уведомления») и что в Windows не включён «Не беспокоить» / фокусировка.

### Б4. Счётчик непрочитанных на панели задач

- Когда в чатах есть непрочитанные, поверх иконки ChatGoose на панели задач
  появляется **красный кружок с числом**.
- Прочитай всё (или владелец отметит прочитанным) — кружок должен исчезнуть.

### Б5. Живая смена «только чтение»

- Подержи приложение открытым 30–60 минут, пока аккаунт живёт обычной жизнью
  (этим занимается владелец). Сообщения появляются сами, без перезапуска;
  внизу в строке состояния обновляется время последнего обновления.
- Отметь любые странности: зависания, пустые списки, окна ошибок, «съехавшую»
  вёрстку — со скриншотом.

## 4. Что отправить владельцу после проверки

1. Заполненную таблицу ниже (можно фото/скрин).
2. Скриншоты всего, что выглядело неправильно.
3. Файл диагностики: Настройки → **«Локальные данные»** → кнопка
   **«Выгрузить диагностику»** — откроется папка с файлом
   `chatgoose-diagnostics-… .json`, пришли его. Ни пароля, ни секретов в нём нет.
4. Версию Windows (Параметры → Система → О системе, строка «Версия»).

После этого владелец просит нажать **«Выйти с этого устройства»** в разделе
«Аккаунт» — либо завершает этот вход со своей стороны. Подключение на этой
машине прекратится — это нормально.
